# 2026-11-27 工作日志

## 从零实现 DSH 插件 dsh-wechat-connecter

完成了微信 → DeepSeek Harness 桥接插件的首版实现。

### 关键结论（DSH 插件 API，版本 0.2.2-rc.5）
- 插件契约：`package.json` 的 `main`/`exports` + `dsh` 字段；宿主半导出 `{ name, inject, apply, Config }`；浏览器半用 `window.__ModuleLoader__.load({ id, factory })` 包裹 esbuild cjs 产物，导出 `{ apply, inject }`。
- 服务访问：`inject` 声明依赖，`ctx.get('agents')` / `ctx.get('connection')` 访问任意服务。
- agent 桥接：`ctx.agents.create({ sessionId, meta:{cwd}, setup })` / `ctx.agents.resume({ resumeSessionId, setup })`；`agent.followup(message)`（message 必须带唯一 `id`）；`agent.whenIdle()`；`agent.session.deriveMessages()` 回读历史。
- 人设注入：在 create/resume 的 `setup(agentCtx)` 回调里 `agentCtx.systemPrompt.section(...)`，只作用于该 agent（不污染用户会话）。
- 管理 RPC：宿主 `ctx.connection.fetch.register({ path:'/api/...', methods:['POST'], requestBody:'buffered', fetch })`；客户端 `ctx.connection.rpc.call('/api', endpoint, {method,payload}, signal)`。
- 设置分区：客户端 `ctx.slots.inject('settings.section', () => ctx.slots.register({name:'settings.section', id, order, label, locale}, render))`。

### 工程结构
- 宿主半 `plugin-src/host/`（tsup → lib/index.js）：config / session-map / persona / reply / bridge / deps / index。
- 浏览器半 `plugin-src/client/`（esbuild → lib/client.js）：api / panels / index。
- Python sidecar `bridge/`（main.py + bg_send.py），依赖 wechatauto-replica==1.3.0.2。

### 环境要点
- Python 3.13 用 WorkBuddy 自带 `~/.workbuddy/binaries/python/versions/<最新>/python.exe`，避免 py 3.15 无预编译轮子。
- Windows git 需 `GIT_SSL_NO_VERIFY=true`（schannel 吊销检查报错）；`gh.exe` 凭据助手路径损坏，push 需 token 内联。
